# MARA BUSINESS

## Local preview

Extract this folder and open dist/index.html in a modern browser. The pages and media use relative paths and can be viewed offline.

## Deploy to Vercel

Import the extracted project root. The included vercel.json selects the static build and publishes dist without a dependency install or build command.

## Quote requests

The form validates entries and downloads a text draft. Online delivery is pending configuration. The hero uses an illustrative packing and cargo video loop.
